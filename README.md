## 📖 Descrição do Projeto
Este projeto consiste em um sistema de monitoramento de temperatura utilizando Arduino e sensor NTC. O programa realiza a leitura da temperatura ambiente e aciona um LED quando a temperatura ultrapassa o valor definido, aplicando conceitos de lógica de programação, estruturas condicionais e integração entre hardware e software.

## ▶ Como Executar
1. Abrir o projeto na IDE do Arduino
2. Conectar o Arduino ao computador
3. Fazer o upload do código para a placa
4. Monitorar a leitura da temperatura no serial monitor

## 🛠 Componentes Utilizados
- Arduino Uno
- Sensor NTC
- LED
- Resistor
- Protoboard
- Jumpers
